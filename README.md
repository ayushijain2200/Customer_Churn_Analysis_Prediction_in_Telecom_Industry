# Customer_Churn_Analysis
## 🔍 Problem Statement
Customer churn is a major issue for businesses. This project analyzes customer data to identify key factors contributing to churn and suggests strategies to improve retention.
## 📁 Dataset
- Telecom customer dataset
- Includes features like tenure, contract type, monthly charges
## 🛠 Tools Used
- Python (Pandas, NumPy)
- Matplotlib, Seaborn
## 📊 Steps Performed
- Data Cleaning (handled missing values)
- Exploratory Data Analysis (EDA)
- Feature analysis
## 💡 Key Insights
- Customers with monthly contracts have higher churn rate  
- High monthly charges increase churn probability  
- Long-term customers are less likely to churn
## 📈 Conclusion
Business should focus on:
- Promoting yearly contracts  
- Offering discounts for high-charge users
